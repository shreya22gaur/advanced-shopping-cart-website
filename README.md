🛒 Advanced Shopping Cart Website

An advanced, fully functional Shopping Cart web application built using TypeScript, focusing on clean architecture, type safety, and dynamic cart management. This project simulates real-world e-commerce cart behavior and demonstrates strong front-end development fundamentals.

🚀 Features

Product listing with dynamic rendering

Add items to cart

Remove items from cart

Increase / decrease product quantity

Automatic price calculation based on quantity

Cart state management using TypeScript

Responsive and user-friendly UI

Clean, modular, and type-safe code structure

🛠️ Tech Stack

TypeScript

HTML5

CSS3

JavaScript (ES6 concepts via TypeScript)



⚙️ How It Works

Products are displayed dynamically on the UI

Users can add products to the cart

Cart updates in real time when quantity changes

Total price is recalculated automatically

TypeScript ensures better error handling and code reliability
